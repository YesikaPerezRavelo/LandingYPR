
# Front-end landing page for new simple fitness family plan\*\*

This is a simple landing page built with HTML, CSS, and JavaScript to display our basic product offerings. It includes user roles, a shopping cart, login system, and product detail pages.



---

## 🚀 Features

- Product listing with “Add to Cart” functionality
- Role-based login system (`admin`, `adminUser`)
- Dynamic navbar/footer injection
- SweetAlert notifications
- Product detail and cart pages
